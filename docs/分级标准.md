# 分级标准（v103 · 可执行版）

> 这套标准的目标：**任何一条快讯，判断结果都能复现、能自证**。
> 不用再靠截图沟通 —— 拿不准的条目，跑 `node tools/explain_grade.js "标题"` 就知道它为什么是这个级别。

---


## 分级总则（7 条 · 由 41 条补漏归纳 · v33）

之前每遇到一种新写法就补一条正则，台账堆到 41 条，用户还得一张张发纠错单。
现在把共性抽成 7 条原则 —— **判 A 只需问四句话**：

> ① 主体是定价方吗？ ② 动作已经落地了吗？ ③ 说的是资产本体吗？ ④ 幅度是价格幅度吗？
> 四句都是「是」才进 A；任何一句是「否」，落到 B（可查）或 C（不进流）。

| # | 原则 | 判据 | 代码位置 | 台账 |
|---|---|---|---|---|
| P1 | **事件 vs 非事件** | 预告、日程、观点、回应、纪要、会议、假设句都不是事件 | `SPEECH_NOTICE` / `0.143 会议` / `0.144 弹劾` / `NE.TALK` | 17,20,21,35,36,38 |
| P2 | **主体分量** | 只有央行/部委/国务院/交易所/国家元首/国际组织有定价权；协会、外围央行、投行、公募、民间数据只有参考价值 | `ASSOC_SUBJ` / `0.142 外围央行` / `NE.PRICE_MAKER` | 16,22,23,34,41 |
| P3 | **动作落地** | 宣布/实施/生效/签署/征收/开展才算；喊话、助力、拟、有望、回应、资金流播报不算 | `NE.LANDED` / `NE.ROUNDUP` / 互换便利闸 / 收储规模闸 | 18,19,36,37,42~47 |
| P4 | **幅度阈值（方向无关）** | 核心指数 ≥3%、重要商品 ≥5%、龙头个股 ≥8% 或涨跌停；原油 ≥90 美元 + 方向动作；**涨跌都算** | `0.25` / `croPillar` 支柱 2·3 | 27~33 |
| P5 | **数量口径 ≠ 价格幅度** | 进口/出口/产量/库存/营收/净利/销售额/持股比例的 % 一律不计入波动阈值 | `maxPricePct()` / `PRICE_WORD` / 财报语境闸 | 15,33 |
| P6 | **资产本体 vs 蹭名/集合** | ETF、基金、成分股、行业指数、成交额、盘后汇总、A 股蹭美股名都不算本体 | `INDEX_NOT_SELF` / 蹭名闸 / `NE.ROUNDUP` | 37,39,40 |
| P7 | **分类优先于级别** | 地缘事件不归商品、公司公告不归贵金属、储备数据不归地缘 | `croCat()` 地缘前置 / `FIRM_HEAD` | 24,25,26,15 |

> **P4 补充说明（幅度阈值，v96）**：注：支柱2中的半导体六巨头5%与核心指数2%属于白名单特权闸，优先执行；P4所列的指数3%与龙头8%为全市场通用行情闸，两套阈值并行，支柱2享有优先判定特权。
>
> 也就是说，7.9% 这类「没到 8% 却仍是 A」的稿子不是阈值失效：它在 `croPillar` 支柱 2
> （名单制 ≥5%）就返回了，根本走不到 P4 的通用行情闸。两套口径互不相干，不要误统一。

### 词表驱动，不再堆积正则

四张词表集中在 `news-live-client.js` 的 `NE`：
`PRICE_MAKER`（定价主体）、`LANDED`（落地动作）、`TALK`（非事件语气）、`ROUNDUP`（播报/集合）。
**新机构、新说法只往对应词表加词**，不用重写判定逻辑。
特意不把「观点/解读/拟/回应/将于」收进 `TALK` —— 它们各有专闸，
混进来会误伤「拟回购 60 亿」这种公司公告（实跑踩过）。

### 回归锁

`node tools/test_principles.js` —— 7 组 41 句，全部来自台账原句，按原则分组。
`node tools/test_grade.js` —— 分级细则回归（逐版累加）。
改任何分级规则前跑这两个，绿灯才发版。

### 以后遇到新写法（不用每次手动发纠错单）

1. 拿标题对照上面 4 句话，判断属于哪条原则失效；
2. 若只是**新词**（新机构名、新动词、新栏目名）→ 加进 `NE` 对应词表；
3. 若是**新原则**（四句话都答不出）→ 新开一条 P8，补进总则表和回归锁；
4. 把标题和期望级别写进 `test_principles.js` 对应用例；
5. 两个回归都绿 → 升 `GRADE_VER`、升版本号、发版。
   只有「规则改不动、必须靠人判断」的情况才需要再发纠错单。

## 一、四步流水线（顺序不可颠倒）

```
第 1 步  一票否决黑名单      → 命中即 C（丢弃），流程终止
第 2 步  S 级：全球级海啸     → 命中即 S，流程终止
第 3 步  A 级：6 大支柱硬门槛 → 命中即 A，流程终止
第 4 步  其余                → B
```

**C 级一律不入流。** 11-05 试过把「带硬信息的 C」放进「C 级 · 待复核」兜底区，
当天被否：「C 还是不要上了，太多太乱。」
误判的正解是**补规则**（见 `docs/误判台账.md` 的 7 步补漏流程），
不是把判低的东西重新摊回用户面前。

**样本来源（v82 · 本地版）**：App 内长按卡片 0.55 秒可手工改判 S/A/B/C，
面板下方**自己填一句原因**（不给预设选项，v79 那套维度不对），改判立刻生效并记入
「设置 → 标级纠错」的纠错单；攒够一批点「复制」，一次性贴回会话，
按 7 步流程批量补漏。纠错单自带规则版本（v33）与导出时间，
拿到后用 `tools/trace_grade.js` 复现每条的原判定路径，再定点改条款。
改判只覆盖本机显示，**不改规则**，所以规则仍需人工迭代。

**v87 新增的几道「看事件本质，不看热搜词」的规则**（详见误判台账 20~30）：

| 情形 | 判定 | 为什么 |
|---|---|---|
| 预告式讲话（将于/即将 + 发表讲话/演讲/出席），非四大央行一把手 | C | 日程不是事件，标题里一个信息都没有 |
| 四大央行一把手（鲍威尔/拉加德/植田/贝利/潘功胜）的预告 | B | 「今晚有大戏」值得知道，但仍不是事件本身 |
| 行业协会（世界黄金协会/中钢协/有色协会/汽车协会…）的观点与统计 | B / 机构观点 | 协会没有定价权，数据也只是口径比较 |
| 能源基础设施被打击（炼油厂/炼化/油库/输油管/LNG + 遭袭/起火/爆炸） | A / 地缘 | 直接从全球供给里扣掉一块产能，当天就能推油价 |
| 关键航道受损（霍尔木兹/红海/曼德/苏伊士 + 油轮 + 起火/遭袭/封锁） | A / 地缘 | 同上，影响的是通道而不是某一国 |
| 原油绝对价位 ≥90 美元（**涨跌都算**） | A / 能源 | 90 以上已是供给冲击区间；跌穿关键位比涨破更危险（止损盘/被动平仓都在跌的一侧） |
| 商品主力合约单日 ≥5% | A（能源类归能源） | 3.5% 那条只覆盖原油，LPG/燃料油/焦煤同样能推价格 |
| 美股科技龙头盘前/盘中 ≥10% | A / 美股 | 巨头暴跌是事件，不是盘面播报 |

**v88（行情类口径修正 · 用户原话「重要商品/指数/龙头个股暴涨暴跌都进 A」）**

| 情形 | 判定 | 阈值 | 不算的情形 |
|---|---|---|---|
| 原油：绝对价位 + 方向动作 | A / 能源 | ≥90 美元，**涨跌不限** | 公司官方售价（OSP/售价为）；只报价无方向 |
| 重要商品主力合约 | A / 能源·重要快讯 | 单日 \|%\| ≥5 或涨跌停；有色/黑色/农产品都算 | 没有具体幅度的板块综述 |
| 核心指数 | A / 指数 | 单日 \|%\| ≥2 | ETF 成交/份额、成分股、行业指数（如标普1500住宅建筑商） |
| 龙头个股 | A / A股·美股 | 单日 \|%\| ≥7 或涨跌停 | 财报口径（净利/营收/销售金额/同比）、目标价评级、A股蹭美股名（博通集成） |

另外三类「不是事件」的闸：外围国家央行行长的个人表态 → B；会议/论坛/座谈会报道（无决定/印发/发布）→ B；
会议纪要与私营机构就业数据（Revelio/ADP/挑战者）→ B。

**关键设计**：A 级不是「有点重要」，而是「能改变一个百亿组合的仓位」。
判断时只问一句话：**这条消息会不会让我明天开盘前动手调仓？** 不会 → 最多 B。

## 二、第 1 步：一票否决黑名单（→ C，丢弃）

| 类别 | 判定 | 典型样本 |
|---|---|---|
| **非核心经济体常规数据** | 新加坡/印尼/马来/越南/菲律宾/泰国/阿根廷/土耳其/墨西哥/巴西/南非/澳/加/瑞士/瑞典/挪威 等国的 GDP、CPI、PPI、PMI、零售、失业、贸易帐 | 「新加坡9月零售销售 -1.0%」「印尼 Q3 GDP 5.47%」 |
| **零售终端与民生价格** | 金饰克价、水贝价、成品油每升、生猪、蔬菜粮油、茅台批价 | 「国内金饰价格较昨日上涨逾40元/克」 |
| **边缘板块异动** | 影视院线/电影票房/短剧/旅游/景区/酒店餐饮/生态环保/水产养殖/纺织服装/预制菜/游戏版号 + 涨跌词 | 「午后电影板块拉升」 |
| **纯观点与标题党** | 以「观点/专栏/评论/分析/解读/前瞻/展望/研判」开头；设问句（…吗/…呢）；「专家称」「机构认为」 | 「分析：石油将英国通胀率推升至3.5%」 |
| **行业会议与协会发言** | 协会/学会/商会 + 领导/会长/秘书长 + 表示/称/发言 | 「中钢协某领导：钢铁行业要做好长期过冬准备」 |
| **远期规划愿景** | 规划/愿景/蓝图/纲要/行动方案（非部委正式印发） | 「印尼2028粮食规划发布」 |
| **投行券商观点** | 机构名 + 冒号开头 + 预测性表述（带「宣布/落地/签署」的除外） | 「摩根士丹利：中期选举后美国经济有望迎来上行空间」 |

> 例外：小国若发生**政权颠覆、主权违约、本币单日崩盘 >10%**，不进黑名单。

## 三、第 2 步：S 级（年均数次，全屏红框）

| 类型 | 硬门槛 |
|---|---|
| 大国规则颠覆 | 中美欧日最高层「924 新政」级组合拳；美联储**非例行**降息/加息 ≥50bp |
| 大国全面对抗 | 中美对**全品类**商品加征关税，或税率 **>30%** |
| 地缘质变 | 核大国/中东全面开战 + **关键海峡封锁**或全球航运实质中断 |
| **重大冲突结束** | 停战/停火/和平协议**已签署或生效**；正式宣布战争结束（v76 新增，用户口径 11-05） |
| **贸易战结束** | 贸易战/关税战正式终止；中美签署贸易协议（v76 新增） |
| 系统性踩踏 | 纳指/标普单日 **−4%** 以上；A 股 **5000+** 只跌停 |
| 金融机构倒闭 | G-SIBs 或千亿级金融机构实质破产 |

**注意**：S 级只认「已经发生」。任何「被曝/或将/最早下周/即将签署」都降级。

**战争与贸易战的「结束」和「开打」同级**——用户口径（11-05）：
「S 级除了重磅政策、关税战开打和美伊战争这种级别的开战外，
假设俄乌签停战协议也是能算的，即重大战争的结束也是 S，包括贸易战的结束。」

判据必须是**签了 / 生效 / 正式宣布**：
「俄乌签署停战协议」→ S；「俄乌停火协议谈判陷入僵局」→ B；
「俄乌即将签署停火协议」→ A（预期，未落地）。

## 四、第 3 步：A 级 6 大支柱（硬门槛，必须命中其一）

### 支柱 1 · 企业资本动作与战略供应链

| 类型 | 门槛 |
|---|---|
| 回购 | **回购 + 注销 + ≥10 亿 → A**（注销是必要条件）；**只回购不注销 → ≥50 亿才 A**；其余 1 亿以上 → B；**<1 亿 → C** |
| 大象被吞并 | 被收购方本身是巨头/千亿级（或控制权变更），才改变行业格局与指数权重 |
| 巨头危机 | 千亿市值实控人/董事长被留置、立案；破产重整 |
| 供应链断供 | 实体清单对华为/中芯/寒武纪断供（先进制程/HBM/EDA） |
| 停产事故 | 行业前三龙头停产大修/爆炸 |

> 不及门槛的公司新闻 → **B**（保留可查，不占重点）；「提议/拟/筹划」阶段 → **C**。

### 支柱 2 · 全球龙头与核心指数

| 类型 | 名单 | 门槛 |
|---|---|---|
| 半导体风向标 | 台积电、英伟达、SK海力士、三星电子、ASML、美光 | 单日涨跌 **≥5%**；或火灾/停产/旗舰延迟 |
| 核心指数 | KOSPI、日经225、欧洲斯托克50、纳指期货 | 单日涨跌 **≥2%** |

> 台湾加权、恒指、上证等不在名单内 → B。

### 支柱 3 · 战略大宗与汇率

| 类型 | 门槛 |
|---|---|
| 黄金 | COMEX/伦敦金 **≥2%** 或创历史新高（只认期货现货，**不认黄金股/ETF/板块**） |
| 原油 | 布伦特/WTI **≥3.5%**（排除燃料油/沥青等下游化工） |
| 天然气 | 欧洲 TTF / 美国 Henry Hub 有明确涨跌 |
| OPEC+ | 紧急/非例行会议决定减产增产 |

> **量 ≠ 价（v76）**：这里的百分比必须描述**价格**。
> 「西班牙9月原油进口同比下降7.4%」里的 7.4% 是**进口量**，
> 不是油价跌幅 —— 用户点名这条不能算 A。凡是被
> 进口/出口/产量/库存/消费量/加工量/开工率/钻井数 修饰的百分比，
> 一律不计入价格阈值（见 `maxPricePct`），这类数据落 **B 宏观数据**。
> 另外「外围经济体（西班牙/意大利/荷兰/日本/韩国…）的量类统计」
> 也直接判 B —— 一国进口量对全球定价没有解释力（不含美国 EIA 库存）。
| 关键航道 | 霍尔木兹/曼德海峡/红海 商船遇袭、断航、封锁 |
| 汇率 | 离岸人民币单边 **≥400 点**；或央行稳汇率工具（外汇存款准备金、离岸央票） |
| 战略资源 | 稀土/镓/锗/锑 出口配额；铜矿/锂矿/铁矿不可抗力停产 |
| 日元异动 | USDJPY 日内振幅 ≥2.0%，或日本财务省与日本央行宣布实施实质性外汇干预 → **A 级「外汇与流动性」** |

### 支柱 4 · 核心经济体政策与数据

| 类型 | 门槛 |
|---|---|
| 中国政策落地 | 降准降息、LPR、买断式逆回购、国债买卖、SFISF、PMI 破 50、存量房贷下调、特别国债下达 |
| 美国数据 | 非农/CPI/PPI 与预期有明显偏差（注：严格排除ADP与挑战者等民间数据，民间统计一律只落B级） |
| 四大央行表态 | **行长/主席/正式决议**才算（管委、委员、官员个人 → B） |
| 关税动作 | 有实际征收/落地/反制（全面对抗才升 S） |
| 救市 | 平准基金、汇金、国家队、降首付、放松限购、收储 |
| 资金面 | ETF/宽基 净流入百亿级以上 |
| 制度级 | 交易所并购重组新政、量化新规、公募费率改革、险资权益比例 |
| 核心金融数据拐点 | 中国央行发布的单月社融增量与预期偏差 ≥5000 亿元，或 M1 同比增速出现历史性见底拐点 → **A 级「中国宏观」** |

> 例行逆回购（净回笼/净投放）→ B，只有买断式/首次创设才算政策动作。

### 支柱 5 · 产能出清与涨价

行业协会正式发布控产限价公约 + 联合核查；或存储原厂（三星/海力士/美光）集体涨价函 ≥15%。

### 支柱 6 · 制度级改革

程序化/高频量化报备与撤单收费新规；公募费率改革落地；险资权益比例上调正式文件。

## 五、第 4 步：B 级（有信息量，不占重点）

常规财报、小额增减持、常规合同、行业会议纪要、非核心指数涨跌、
官员个人表态、例行央行操作、B 级地缘（谈判/表态/常规战况）、
不达门槛的公司公告、盘面统计（成交额/两融/北向）。

## 六、附：几条容易判错的边界

| 标题 | 判定 | 原因 |
|---|---|---|
| 韩国KOSPI指数日内重挫6% | **A** | 核心指数 ≥2% |
| 台湾加权收跌3.2% | **B** | 不在 4 大核心指数名单 |

## 判重与折叠（v86）

同一件事在不同源里会被改写：换人名（隆巴尔代利→Lombardelli）、换动词（增至→升至）、
换句式。实测这类标题的字符相似度只有 0.40~0.77，原来 0.82 的门槛全部漏网 ——
这就是「重复怎么改都还在」的根因。

现在判重是三道，逐级放宽：

| 闸 | 判据 | 窗口 |
|---|---|---|
| ① 字面 | `sameNews()` 归一后相似度 ≥0.82 / 包含 / 尾句 ≥0.8 | 3 天 |
| ② 统计发布 | 主体+指标+期别三元组一致（同比/环比/初值算同一份公报） | 3 天 |
| ③ 同主体同议题 | 同机构或同主体前 3 字 + 同议题 + 字面 ≥0.35 + 无数字冲突 + 方向不打架 | **6 小时** |

第③道是新增的，`sameSyncEvent()`；宁严不宽的配套：决定类（含"宣布/决定/维持/基点"）
遇到加息↔降息直接算两件事（`dirConflict`），表态类不判方向。

**改判的持久化（v87 修）**：用户手工改判存两处 —— `mm_fix_v1` 的 id→级别映射，
以及池子里那条记录的 `level`。原来有一个坑：另一家媒体报了同一件事，
走 `mergeNews()` 跨源合并时会**按规则重算 level**，把用户改的级别悄悄盖回去，
表现就是「改判后刷新了还是没改」。现在：
- `mergeNews()` 遇到 `target.fixed`（改判过的条目）**不再重算**；
- app.js 在每次合并后补一次 `fixApply(dup)`；
- 改判成功立刻 `poolSync()` 落盘。

**子卡详情（v87）**：折叠时间轴里的每一条（子卡）都能单独点开 ——
小字只截 34 个字，长标题看不全；子卡同样支持长按改判。

**母子卡**（`foldByTopic`）与判重是两件事：判重合并"同一件事的两套写法"，
母子卡把"同一机构同一议题的一批不同说法"折成一张卡（右上角「同题 N 条」，
点开看时间轴）。两层折叠：先按标的（行情），再按主题簇，母卡优先取级别最高的那条。

## 同一商品涨跌：12 小时母卡（v91）

**用户口径（11-05）**：「同一商品涨跌新闻12小时内只留母卡折叠」。

原先行情折叠是「主标的 + 自然日」，同一商品的稿件常挂到不同标的
（布伦特那条挂 BRENT+WTI、另一条只挂 WTI），于是一屏散着五六张
「原油涨 / 原油跌 / 布油站上…」。现在在 `app.js` 里加了第三层折叠：

| 环节 | 做法 |
|---|---|
| 归一键 | `CM_ALIAS` 按**标题里写明的商品名**归一（布伦特/布油 → BRENT，现货黄金/金价 → GOLD…）。一个键 = 一个品种，不按「化工品 / 黑色 / 油脂」板块合并 |
| 涨跌判定 | `CM_MOVE`（涨/跌/站上/失守/涨停…）；`CM_NOT` 排观点、ETF、板块、收评、数量口径；`CM_EVENT` 排供给冲击、政策、库存发布等独立事件稿 |
| 时间窗 | **12 小时会话窗**：以簇内最新一条为锚，往前 12 小时内归一张；超出的另起一张。簇内跨度恒 ≤12h，24 小时回溯最多两张母卡 |
| 方向 | 涨和跌**不拆** —— 同一段行情的两个时点，时间轴里连着看才完整 |
| 母卡 | 取级别最高的那条（同级取最新），徽标「同商品 N 条」；子卡按时间**降序（最新在上）**，可点开详情、可长按改判 |
| 不回缝 | 商品簇定稿后跳过 `foldByTopic`，否则刚切开的 12h 边界会被按自然日缝回一张 24h 大卡 |

**刻意不做 direct 标的兜底**：实跑踩过「港股收评：恒生指数涨3.67%」的 direct 里
挂着 GOLD（贵金属板块联动），靠标的会把 8 条股指收评并进黄金母卡。
与 `clusterKey` 同一原则 —— 只按标题里明确写出来的主体聚，没写商品名宁可不并。

**词表驱动**：以后出现新品种 / 新说法，只往 `CM_ALIAS`、`CM_NOT`、`CM_EVENT` 加词，
不用改折叠逻辑。回归锁 `python tools/test_fold.py`（14 项，真浏览器跑）：
同一商品 5 种写法折 1 张、12h 窗外另起 1 张、不同商品不合并、
误挂 GOLD 的股指收评与黄金股 ETF 不进簇、母卡取最高级别、徽标文案。

**口径边界**：布伦特 / WTI / 泛称「原油」目前是三个不同的键（按「同一商品」字面，
它们是三个品种）。若要把原油族并成一张母卡，把 `CM_ALIAS` 里这三行指向同一个键即可。

## v98 · 增减持交易额 ≥100 亿 → A（11-06）

**用户原话**（11-06 02:00）：「英伟达：股东减持1.5%股份，交易额150亿元绝对算a」。

### 根因

`holderAmount()`（v96 为「金额 ≥1 亿」分支加的）其实**抽得到**这三种写法（实测都是 150），

```
IF holderQualified（= 比例 ≥1% 且 (龙头 或 金额 ≥1 亿)）

**为什么不再要求 `croPillar`**：本条金额门槛本身就是支柱 1 新增的重磅条件，
再套 `croPillar` 会把它打回 B，等于没改。只保留 `aCap` 旧闸挡常规战况 / 记录型稿子。

### 13.1 四个平台的标红字段（2026-11-06 实测）

### 13.2 漏抓的结构性根因：只看最新 30 条

财联社 `get_roll_list` 单页 `rn` 上限是 **50**（`rn=60` 直接返回 0 条），
rn=50 只覆盖约 107 分钟。而旧代码每轮只拉一页 30 条 —— **页面一关，中间所有稿子永久丢失**。

更关键的是：**翻页必须带 `refresh_type=1`**。只传 `last_time` 时服务端直接忽略该参数，
连续 5 页返回同一批 30 条（这就是「以为在翻页、其实一直在第一页」）。

- 加上 `refresh_type=1` 后，`last_time` 逐页前推正常工作：11:27→10:39→09:29→08:43 连续前推；
- 24 小时全量 = **13 页 / 650 条 / 3 秒**；
- 实测证据：用户反馈的「何立峰在北京调研时指出…」是 11-05 21:45 的**加红稿**，
  「韩国财政部：不排除美股下跌…外溢效应」是 11-06 07:38 的普通稿 ——
  两条都在财联社电报里，但旧版只看最新 30 条，早就滚过去了。

**① 财联社回溯翻页**（`fetchCls`）

每轮：从 now 往回翻，翻到 ctime <= 游标 或 <= now-12h 或 满 6 页为止
rn=50、refresh_type=1（必需）
第 2 页以后失败 → 保留已抓到的，不整体报错
```
首次（无游标）回溯 6 页 ≈ 300 条 / 6~12 小时；常态轮询只翻 1 页。

## 15. v114 · 两条纠错规则 + 刷新链路的三个真 bug

### 15.1 纯栏目名汇编稿 → C（不再留 B）

「期货热点追踪」这类标题**本身就是栏目名**，正文是十几个品种的小动态拼盘，
没有单一事件主体。旧逻辑 `DIGEST` 命中后统一给 `B / 市场综述`，
且 `grade()` 里「平台标红 → 从 C 抬到 B」的兜底会再拉一次。

- 新增 `PURE_DIGEST`：整串只匹配栏目名（可带 期货/A股/股市/商品/黄金/原油/外汇/债市 前缀）
- 命中 → `['C', '无实质内容']`
- `VETO_CATS` 补 `无实质内容`，禁止标红兜底抬级
- 保护：`黄金热点追踪：央行连续三月购金` 带具体事实，仍是 `B / 市场综述`

### 15.2 多家公司集体回购 / 增持 → A

「10 家沪市公司宣布拟使用回购增持贷款」旧判 `B / 公司事项`。
一两家回购是公司自身事项；十家以上同方向集体行动，背后通常是
「回购增持再贷款」这类政策资金，影响整体风险偏好 → 按板块/资金面给 A。

`GROUP_BUY = /(?:\d{2,}家|数十家|多家|一批|十余家)[^，。；]{0,12}(?:回购|增持)/` → `A / 公司事项`

### 15.3 六个代理源数据互相串（`/__proxy`）

**根因：Service Worker 的 `ignoreSearch: true`。**
为了命中带 `?v=` 的静态资源，`caches.match` 忽略了 query，于是
`/__proxy?u=<财联社>` 与 `/__proxy?u=<格隆汇>` 变成同一个缓存键 ——
第二个源直接拿到第一个源的响应，格隆汇解析器读到财联社 JSON，
抛「无有效条目」→ 回退第三方中转 → 时通时断、标红忽有忽无。

修法两处：
1. `sw.js` 对 `/__proxy` 直接 `return`，完全不接管
2. 目标 URL 从 query 改到**路径**：`/__proxy/<token>/<base64url(url)>`，
   token 每次不同，同时绕开平台网关「按路径缓存、无视 no-store」的行为

实测：格隆汇 47727B / 20 张 `live-card`、财联社 32596B HTML、见闻 35520B JSON ——
三个源各自独立，60 秒内源状态稳定 `11/11` 不再抖动。

### 15.4 重载后「72 条变 11 条」+ 源全变「未接入」

| 现象 | 根因 | 修法 |
|---|---|---|
| 新闻数骤降 | `pool.js` 的 `slim()` **不存 `gv`** → `hydrateFromPool` 拿到的 `gv` 永远 ≠ `GRADE_VER`，每次启动全量重算，重算判 C 的直接丢 | `slim`/`list` 存并透传 `gv`；`merge` 同 id 但 gv 不同时只补 gv；hydrate 重算后写回 `n.gv` 并 `poolSync()`；标红条目重算不成时保留原级 |
| 源显示未接入 | 源状态只在内存，整页重载即清零 | 落盘 `mm_srcdetail_v1`（TTL 30 分钟），`boot()` 先 `restoreSrcState()`；`overscroll-behavior-y` 提到 `none` |
| 首轮 7/11 抖动 | 11 源同时发起（5 个走转发），服务端瞬时并发抓外站 | 失败源隔 900ms 重试一次（仅 4 秒内快速失败的） |

实测（v114 线上）：整页重载 **+0.5 秒**即恢复 40 张卡、源状态原样、在库 230~248 条。

### 15.5 数量口径澄清

- `st.kept` = **本轮抓取**里通过筛选的条数
- `in24` / 在库 = 24 小时内累积的平台标红条数

以前 UI 写「N 条入库」用的是前者，用户拿它跟列表「全部 N」对照永远对不上。
